## ✨ Overview

This project is a modern, high-performance web portfolio designed to showcase my skills as a Software Developer and Web Designer. It features a sleek dark/light mode, internationalization support (EN/ES), and a highly responsive design optimized for all devices.

## 🛠️ Tech Stack

- **Core Framework:** [Astro 4.x](https://astro.build/) - For lightning-fast performance and component islands.
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS for custom, responsive layouts.
- **Typography:** [Inter Font](https://fontsource.org/fonts/inter) - Modern and highly readable sans-serif.
- **Icons:** [Simple Icons](https://simpleicons.org/) - Consistent and recognizable brand marks.
- **Animations:** `@midudev/tailwind-animations` - Subtle, premium motion effects.
- **Platform:** GitHub Pages deployment with automated workflows.

## 🌟 Key Features

- **🌐 Dual Language Support:** Full support for English and Spanish, with a fast and intuitive toggle in the navigation.
- **🌓 Dark/Light Mode:** Seamless theme switching with system detection and persistence.
- **📱 Mobile First:** Every component is meticulously designed to be fully adaptable to mobile, tablet, and desktop screens.
- **✉️ Contact Integration:** Integrated contact flow using EmailJS for direct communication.
- **⚡ SEO Optimized:** Fast load times, semantic HTML, and proper meta tags for better search engine visibility.
- **📂 Component-Based Architecture:** Modular structure using Astro components for reusability and clean code.

## 📁 Project Structure

```bash
├── 📁 public/            # Static assets (icons, images, PDFs)
├── 📁 src/
│   ├── 📁 components/    # Reusable Astro components (Hero, Projects, Header, etc.)
│   ├── 📁 i18n/          # Internationalization dictionaries
│   ├── 📁 layouts/       # Main page layouts
│   └── 📁 pages/         # Application routes (EN/ES Index pages)
├── 📄 astro.config.mjs   # Astro configuration
├── 📄 tailwind.config.js # Tailwind custom theme and animations
└── 📄 package.json       # Project dependencies and scripts
```

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ManuelRomer0/MRPort-v1.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
